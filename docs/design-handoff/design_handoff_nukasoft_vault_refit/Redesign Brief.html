NukaSoft.AI — Design Memo

Vault 69 Command Center, refit

Re-skinning the Skippy Dashboard from Pip-Boy phosphor green to the canonical NukaSoft Vault look. Flatter, more readable, built for two rooms: the big board on the wall, and the iPad in your hand.

What I read before designing

The linked skippy-dashboard codebase (React + Tailwind, CSS-variable theming, 9 routes), the README screenshots, and the NukaSoft design system — especially its Skippy Dashboard UI kit, which establishes the app chrome: Cola Brown shell, Nuka Red top bar, cream type, rad-yellow section labels, IBM Plex Mono for data.

Assumptions

  • Vault theme is home base. The app lives in dark Cola Brown (#3D1C0B family) so long sessions on a wall display don't burn a red rectangle into the room. Red is spent deliberately: the top bar, active states, primary buttons, alerts.
  • Two sanctioned themes, not seventeen. Vault (dark, default) and Terminal (a NukaSoft-flavored CRT green as a nod to the current look). The 15 fan themes retire; the CSS-variable architecture stays so they could return as a community pack.
  • CRT is a toggle — scanlines/vignette off by default (that's the "flatter, more readable" ask), one switch to bring the romance back.
  • Crew voice everywhere. Sessions are voyages, agents are Crew (Artificial Persons), subagents are deckhands, the feed is the Captain's Log, timestamps render as stardates alongside clock time. Skippy narrates empty states.
  • A Library view is added for the PDF reports/binders you mentioned, designed for tapping on an iPad.

LayerDecision
TypeAbril Fatface for page titles only. Josefin Sans for UI. IBM Plex Mono for every number, ID, path, and stardate — data always reads as data.
FlatnessNo glows, no gradients, no soft shadows inside the app. Flat fills, 1px hairlines, dashed dividers for data lists. Letterpress shadow reserved for the brand mark and primary buttons.
StatusOne five-state vocabulary across all views: working / connected / idle / completed / error. Filled dot + uppercase mono label, same colors everywhere.
DensitySame as today, but with a real grid: 4px rhythm, aligned columns, right-aligned numerals.
ReadabilityMinimum 14px mono for data, 16px body. On the TV profile everything scales up ~35% — readable from a couch, not a desk chair.
